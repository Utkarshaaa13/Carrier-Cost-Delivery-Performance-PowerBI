# Are We Paying More for Better Delivery?

A Power BI case study analyzing carrier cost, delivery performance, and how carrier performance changes across shipping distance segments.

**Tools:** Power BI | Power Query | DAX  
**Dataset:** 2,000 shipment records | 7 carriers

## Business Questions

1. Which carriers provide the best and weakest value when cost and delivery performance are evaluated together?
2. How does carrier performance vary across distance segments?
3. Where should the business investigate or adjust carrier allocation?

## Project Workflow

1. Data Quality & Validation
2. Power Query Transformation
3. Delivery Performance Logic
4. DAX Measures
5. Distance Segment Analysis
6. Carrier Cost & Performance Analysis
7. Dashboard Development
8. Business Recommendations

Detailed documentation of the measures used in the analysis:

- On-Time Shipments
- On-Time Delivery %
- Lost / Returned / In-Transit Measures
- Cost Rank by Distance
- Dynamic Distance Benchmarks

### Data Preparation
Data-quality checks, Power Query transformations, estimated delivery date logic, and distance segmentation.

### Analysis & Validation
Metric validation, filter-context decisions, distance-level analysis, and analytical iterations.
